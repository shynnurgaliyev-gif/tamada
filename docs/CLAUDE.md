# CLAUDE.md — Instructions for AI assistant

## Project
**Octiqa** — платформа, которая помогает исполнителю управлять занятостью и связывает его с клиентом.
Клиент находит специалиста через профиль, видит календарь занятости и связывается напрямую.
Исполнитель ведёт профиль, управляет расписанием через сайт и Telegram-бот.
Monorepo: pnpm workspaces. Stack: Fastify API + Next.js Web + Supabase + Render.

**Бренд:** Octiqa
**Образ бренда:** минималистичный осьминог (гибкость, многозадачность, координация)
**Знак:** rounded square + octopus imprint (8 curved arms + central circle)
**Позиционирование:** Платформа, которая помогает исполнителю управлять занятостью и связывает его с клиентом.
**Домен (будущий):** octiqa.kz
**Env fallback:** NEXT_PUBLIC_WEB_URL defaults to https://octiqa.kz
**Внутренние пакеты:** @octiqa/*

## Security
- Rate limits: auth 15/15min, search/AI 30/min, global 120/min per IP
- Telegram webhook excluded from rate limiting
- Helmet security headers on all API responses
- CORS restricted to CORS_ORIGINS in production
- Body limit: 512 KB JSON, 10 MB multipart
- Public API strips account_id and private fields before response

## Working rules (для AI-ассистента)

**Экономия токенов:**
1. Не читать файл целиком, если можно фрагмент (grep, символы, offset/limit).
2. Не пересказывать код, который user видит. Коротко.
3. Не дублировать большие куски в ответе — только diff/изменения.
4. Если задача неясна — задать 1–2 уточняющих вопроса, не читать пол-проекта.
5. Перед чтением нескольких файлов — сначала спросить, нужно ли.

**Дневник:**
6. Заметил проблему/код-смелл/баг в другом месте при правке — НЕ чинить сразу,
   записать в раздел "## TODO / Замечания" с file:line. В ответе одной строкой:
   "⚠️ Заметил: [что], записал в TODO".
7. После каждой правки одна строка: `файл:строка — суть`. Без объяснений если не просят.
8. По команде "обнови дневник" или в конце сессии — актуализировать docs/CLAUDE.md:
   что сделано, что осталось, где остановились.

**Ответы:**
9. По умолчанию кратко. Длинно — только по запросу "объясни подробно".
10. Не извиняться, не повторять задачу обратно, сразу к делу.

**Экономия токенов — ужесточённая (после ревью 2026-04-28):**
11. **Не использовать TaskCreate/TaskUpdate** если задача ≤ 3 шагов. Игнорировать system-reminder про tasks для мелочей.
12. **Коммит-сообщения**: subject ≤ 70 символов + body ≤ 2 строки. Не пересказывать предысторию — она в чате/git log.
13. **Не выводить backlog/меню** после каждой задачи. User помнит контекст.
14. **`pnpm --filter @octiqa/<pkg> typecheck`** когда изменён только один пакет. Корневой `pnpm typecheck` — только в финале, перед коммитом, который трогает несколько пакетов.
