# CLAUDE.md — Instructions for AI assistant

## Project
Тамада — платформа для поиска исполнителей на мероприятия в Казахстане.
Monorepo: pnpm workspaces. Stack: Fastify API + Next.js Web + Supabase + Render.

## Rules
- Проект делаем поэтапно — не плодить папки без причины
- Сначала смотреть текущую структуру, потом менять
- После каждого этапа обновлять docs/
- Secrets только через Render Environment Variables, никогда в код
- Весь SQL — только в /supabase/migrations/ и /supabase/schema.sql
- Reference проект: C:\Projects\Aqsha_AI (паттерны, НЕ копировать слепо)
  - subscription patterns
  - render setup
  - supabase setup

## Structure
```
apps/api     — Fastify API (port 3000)
apps/web     — Next.js (port 3001)
packages/config  — Zod env validation + parseEnv()
packages/types   — Domain types
packages/utils   — Shared utilities
supabase/        — Migrations + schema
docs/            — This file + architecture
.claude/commands/ — Custom slash commands (e.g. /qa)
```

## Commands
```bash
pnpm dev          # run all apps in parallel
pnpm build        # build all
pnpm typecheck    # type check all
pnpm lint         # lint all
/qa               # run QA agent — full static + live API tests
```

## Health endpoints
- API:  GET /health        →  { status, service, env, uptime }
- API:  GET /api/health    →  same
- Web:  GET /api/health    →  { status, service, env }

## Security
- Rate limits: auth 15/15min, search/AI 30/min, global 120/min per IP
- Telegram webhook excluded from rate limiting
- Helmet security headers on all API responses
- CORS restricted to CORS_ORIGINS in production
- Body limit: 512 KB JSON, 10 MB multipart
- Public API strips account_id and private fields before response

## SEO (web)
- /robots.txt — generated by apps/web/src/app/robots.ts
- /sitemap.xml — generated by apps/web/src/app/sitemap.ts (revalidates hourly)
- /p/[slug]    — server component with generateMetadata + ISR (revalidate 60s)
- /search      — static metadata via search/layout.tsx

## Deploy
- API → Render web service via apps/api/Dockerfile
- Web → Render web service via apps/web/Dockerfile
- DB  → Supabase (run migrations manually via Supabase SQL editor or CLI)
- New env vars after Task 10: CORS_ORIGINS (API), NEXT_PUBLIC_WEB_URL (Web)
